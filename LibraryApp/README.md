# LibraryApp

Этот проект представляет собой простое консольное приложение для управления библиотекой. Позволяет добавлять книги, выдавать их читателям и возвращать обратно. 
В проекте реализована обработка граничных случаев (попытка выдать несуществующую книгу, повторная выдача, возврат невыданной книги) и проведен статический анализ кода.

## Установка

1. Откройте файл решения (.sln) в Visual Studio.
2. Соберите проект (Ctrl+Shift+B).

## Использование

Для запуска приложения нажмите F5 (с отладкой) или Ctrl+F5 (без отладки).

## Структура проекта

- Book.cs: Класс предметной области, описывающий книгу (Id, Title, Author, IsAvailable).
- Library.cs: Класс, управляющий коллекцией книг. Содержит методы добавления, выдачи, возврата и поиска.
- Program.cs: Точка входа в приложение, демонстрирующая работу трех сценариев.
- TEST_REPORT.md: Отчет о тестировании и найденных дефектах.

## Данные

Приложение не использует внешние базы данных. Все данные хранятся в оперативной памяти в коллекции List<Book> и заполняются программно при запуске для демонстрации работы.
